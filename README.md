Proyecto: Buscaminas (Examen POO)

Proyecto desarrollado para la asignatura de Programación Orientada a Objetos en la Universidad Politécnica Salesiana. El sistema implementa el clásico juego "Buscaminas" utilizando Java, aplicando el patrón de arquitectura MVC y buenas prácticas de desarrollo.

🚀 Características Técnicas
Paradigma: Programación Orientada a Objetos (POO).

Arquitectura: Modelo-Vista-Controlador (MVC).

Metodología: TDD (Test-Driven Development) con JUnit 5.

Persistencia: Serialización binaria (.dat) para guardar/cargar partidas.

Gestión: Control de versiones con Git y GitHub.

🛠 Requisitos de Entorno
JDK: Versión 21 o superior.

IDE: Eclipse IDE para desarrolladores Java.

Librerías: JUnit 5 (incluida en el build path).

📥 Instrucciones de Instalación
Clona este repositorio en tu máquina local:

Bash
git clone https://github.com/SguncayP/ExamenPOO.git
Abre Eclipse y selecciona File > Import > General > Projects from Folder or Archive.

Selecciona la carpeta donde clonaste el proyecto.

Asegúrate de que el Project Facet esté configurado para Java 21.

🎮 Guía de Ejecución
Ubícate en el paquete principal.

Ejecuta la clase Main.java como Java Application.

Sigue las instrucciones que aparecerán en la consola para revelar celdas o marcar minas.

🧪 Pruebas
Para ejecutar las pruebas unitarias y validar la integridad del código:

Haz clic derecho sobre el paquete test.

Selecciona Run As > JUnit Test.

Verifica que todas las pruebas resulten en la barra verde.
